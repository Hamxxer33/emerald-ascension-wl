# Emerald Ascension — Whitelist

Polished mobile-first whitelist site for **Emerald Ascension** ([@EmeraldAscen](https://x.com/EmeraldAscen)).

Bio: *2222 Emerald coming on @Robinhoodapp*

## Stack

- Vite + React + TypeScript
- No backend — submissions save to `localStorage`

## Run

```bash
npm i
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Tasks

Both required. Tap opens the URL in a new tab, then marks the task complete:

1. **Follow @EmeraldAscen** → https://x.com/EmeraldAscen
2. **Like, comment, repost, and turn on notifications** → https://x.com/EmeraldAscen (profile until a status post exists)

After tasks, submit wallet (+ optional X handle). Data stays on-device under `emerald-ascension.wl.v1`.
